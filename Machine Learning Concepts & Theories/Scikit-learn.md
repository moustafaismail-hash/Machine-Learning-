# 8. Scikit-learn

## What is Scikit-learn?

Scikit-learn is a popular open-source Python library for Machine Learning. It provides tools for data preprocessing, model training, evaluation, and comparison.

## Main Features

- Data Preprocessing.
- Classification Algorithms.
- Regression Algorithms.
- Clustering Algorithms.
- Model Selection.
- Cross-Validation.
- Model Evaluation.

## Common Scikit-learn Functions

| Function | Purpose |
|---|---|
| `train_test_split()` | Splits data into training and testing sets. |
| `fit()` | Trains the model using data. |
| `predict()` | Generates predictions. |
| `transform()` | Applies a transformation to data. |
| `fit_transform()` | Learns and applies a transformation. |
| `score()` | Returns a model performance score. |
