# 1. Introduction to Machine Learning

## What is Machine Learning (ML)?

Machine Learning is a subfield of Artificial Intelligence (AI) that enables computers to learn from data, identify patterns, and make predictions or decisions without being explicitly programmed for every task.

**ببساطة:** بنخلي الكمبيوتر يتعلم من البيانات ويكتشف الأنماط والعلاقات الموجودة فيها، علشان يقدر يتوقع نتائج جديدة.

## AI vs Machine Learning vs Deep Learning

- **Artificial Intelligence (AI):** The broad field of creating machines that can perform tasks requiring human-like intelligence.
- **Machine Learning (ML):** A subset of AI that allows machines to learn patterns from data.
- **Deep Learning (DL):** A subset of ML that uses multi-layered neural networks to learn complex patterns.
