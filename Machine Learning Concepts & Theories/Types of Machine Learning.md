# 3. Types of Machine Learning

Machine Learning is commonly divided into three main types:

## 3.1 Supervised Learning

Supervised Learning is a type of machine learning where the model is trained using labeled data (input features with their correct outputs).

The model learns the relationship between inputs and outputs to predict results for new, unseen data.

### A. Regression

Regression is used to predict continuous numerical values.

**Examples:**
- Predicting house prices.
- Predicting temperature.
- Estimating student exam scores.

### B. Classification

Classification is used to predict discrete categories or classes.

**Examples:**
- Email Spam Detection (Spam / Not Spam).
- Disease Detection (Positive / Negative).
- Predicting whether a student will Pass or Fail.

## 3.2 Unsupervised Learning

Unsupervised Learning is a type of machine learning where the model is trained using unlabeled data.

The model tries to discover hidden patterns, structures, and relationships in the data without predefined answers.

### A. Clustering

Clustering is the process of grouping similar data points together based on their characteristics.

**Examples:**
- Customer Segmentation.
- Grouping similar documents.
- Grouping customers based on purchasing behavior.

### B. Dimensionality Reduction

Dimensionality Reduction is the process of reducing the number of features in a dataset while preserving as much important information as possible.

**Examples:**
- Simplifying complex datasets.
- Reducing computational cost.
- Visualizing high-dimensional data.

## 3.3 Reinforcement Learning

Reinforcement Learning is a type of machine learning where an agent learns through interaction with an environment.

The agent takes actions and receives rewards or penalties based on the results. Its goal is to learn a strategy that maximizes the total reward over time.

### Main Terminology

- **Agent:** The learner or decision-maker.
- **Environment:** The world in which the agent operates.
- **Action:** A decision made by the agent.
- **Reward:** Feedback received after taking an action.
- **Policy:** The strategy used by the agent to choose actions.

**Examples:**
- Training robots to walk.
- Self-driving cars.
- AI playing video games.
