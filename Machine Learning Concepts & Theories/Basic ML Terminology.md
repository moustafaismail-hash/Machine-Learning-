# 2. Basic Machine Learning Terminology

## Basic Terminology

| Term | Definition |
|---|---|
| Dataset | A collection of data used to train and evaluate a machine learning model. |
| Data Point / Sample | A single observation or record in a dataset. |
| Features | The input variables or characteristics used by a model to make predictions. |
| Label / Target | The correct output or value that the model tries to predict in supervised learning. |
| Model | A mathematical system that learns patterns from data to make predictions. |
| Algorithm | A method or procedure used to train a machine learning model. |
| Training | The process of teaching a model using training data. |
| Testing | Evaluating the model using unseen data to measure its performance. |
| Prediction | The output generated by a trained model for new input data. |

## Training vs Testing

- **Training Set:** The data used to teach the model and help it learn patterns.
- **Testing Set:** Unseen data used to evaluate how well the model performs on new examples.
