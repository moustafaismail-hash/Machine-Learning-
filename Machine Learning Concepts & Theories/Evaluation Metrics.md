# 7. Model Evaluation Metrics

Evaluation Metrics are measurements used to assess how well a machine learning model performs.

## 7.1 Classification Metrics

| Metric | Definition |
|---|---|
| Accuracy | The percentage of correct predictions among all predictions. |
| Precision | The percentage of predicted positive cases that are actually positive. |
| Recall | The percentage of actual positive cases correctly identified by the model. |
| F1-Score | The harmonic mean of Precision and Recall. |

## 7.2 Regression Metrics

| Metric | Definition |
|---|---|
| MAE (Mean Absolute Error) | The average absolute difference between actual and predicted values. |
| MSE (Mean Squared Error) | The average squared difference between actual and predicted values. |
| RMSE (Root Mean Squared Error) | The square root of MSE, expressed in the target variable's unit. |
| R² (R-Squared) | Measures how much of the variance in the target variable is explained by the model.
